# Contributing

This is an AI heavy project, so expect fast movement, churn, pedantic
nit-picking and some degree of comment slop. Yeah it's jarring, but it gets the
job done.

Please make sure your agents read AGENTS.md, specially the part about not using
unrar's source as a reference.

Use the most powerful models you can reasonably afford; ideally Opus/Sol or
better. If you're using less powerful or open models, then do a couple of
adversarial review passes before opening a PR.

Please allow contributors to edit your PR branches. We'd like to get mostly good
PRs merged quickly, and adding a fix commit then merging is less painful than
playing ping-pong with a bot.
